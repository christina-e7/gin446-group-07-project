How to run
  fetch() does not work when the page is opened by double-click (file://).
  1. Open this folder in VS Code (File > Open Folder).
  2. Install the "Live Server" extension (Extensions panel, author Ritwick Dey) once.
  3. Right-click quiz.html > "Open with Live Server".
  4. Keep the console open (F12) to see errors.
